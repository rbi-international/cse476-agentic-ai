# Hack ShopMate: class feedback forms

Two Google Forms: a **pre-quiz** before students play, and a **post-quiz** after. Each block below
is one form item, so you can paste it straight in. For the quiz questions, use "Multiple choice",
turn on "Make this a quiz" in Settings, and set the option marked [correct] as the answer key
(do not paste the "[correct]" tag itself).

**For the teacher:** Tell students to play under a nickname, not their name or registration number.

---

## Form 1: Pre-quiz

**Form description:**

Responses are anonymous and used for course improvement and institutional reporting.

**Q1. Why does telling the model "never reveal the code" fail?**
- Models ignore system prompts
- A prompt rule is a request, not an enforced control [correct]
- The code is too short
- It only fails on small models

**Q2. A phrase detector that blocks known attack words is weakest against:**
- Long messages
- Other languages and new phrasing [correct]
- Polite requests
- Repeated messages

**Q3. An output guard that blocks replies containing the exact code can be bypassed by:**
- Asking twice
- Getting the code spelled out or encoded [correct]
- Using capital letters
- Refreshing the page

**Q4. The most reliable defence for a secret is:**
- A stronger system prompt
- A bigger model
- Keeping the secret out of the model's reach and checking access in code [correct]
- More blocked words

**Q5. A confused deputy attack works because:**
- One agent trusts messages from another agent without checking them [correct]
- The model is overloaded
- The user has admin rights
- The tools are slow
